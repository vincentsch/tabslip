# tabslip serve

Start the local AI gateway

## Usage

```
tabslip serve
```

## Examples

```
tabslip serve
tabslip serve --port 4546
tabslip serve --dry-run --json
```

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.
