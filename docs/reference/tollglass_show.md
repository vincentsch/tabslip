# tollglass show

Show one signed receipt

## Usage

```
tollglass show <id>
```

## Examples

```
tollglass show rcpt_01JB8Y3Q6V9W2N4K8M0P5R7S1T
tollglass show rcpt_01JB8Y3Q6V9W2N4K8M0P5R7S1T --json
```

## Output modes

human, json
