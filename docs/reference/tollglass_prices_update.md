# tollglass prices update

Download and install a LiteLLM price snapshot

## Usage

```
tollglass prices update
```

## Examples

```
tollglass prices update
tollglass prices update --dry-run --json
```

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.
