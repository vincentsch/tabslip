# tabslip show

Show one signed receipt

## Usage

```
tabslip show <id>
```

## Examples

```
tabslip show rcpt_01JB8Y3Q6V9W2N4K8M0P5R7S1T
tabslip show rcpt_01JB8Y3Q6V9W2N4K8M0P5R7S1T --json
```

## Output

Shows text you can read in your terminal.

Use --json to get JSON for scripts and other programs.
