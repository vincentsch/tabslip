# tabslip

Keep signed receipts for AI API calls

## Usage

```
tabslip
```

## Examples

```
  tabslip
  tabslip --port 4546
  tabslip --dry-run --json
```

## Output modes

human, json

## Changes state

This command changes state and honors `--dry-run`.
