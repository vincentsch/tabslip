# tabslip doctor

Check local setup and upstream reachability

## Usage

```
tabslip doctor
```

## Examples

```
tabslip doctor
tabslip doctor --port 4546 --json
```

## Output

Shows text you can read in your terminal.

Use --json to get JSON for scripts and other programs.
